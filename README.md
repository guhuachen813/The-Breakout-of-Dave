# 戴夫突围

《戴夫突围》是一款 2D 幸存者类小游戏。你控制戴夫在户外大地图里走位，戴夫会不断放出子弹攻击从四面八方冲来的僵尸。你要一边躲开敌人，一边选择升级并释放技能，撑过最后一波就能获胜。

## 游戏内容

- 固定户外大地图，镜头跟随戴夫移动。
- 戴夫自动放子弹攻击敌人，玩家不用手动瞄准。
- 橘豌豆、熔岩豌豆、西瓜三种子弹有不同攻击方式。
- 普通僵尸、橄榄球小僵尸、铁桶僵尸、吐毒液远程僵尸会按波次出现。
- 战斗中会出现三选一升级，可以强化伤害、发射频率、移动速度或攻击范围。同时可释放技能。
- 戴夫与僵尸触碰时会掉血并触发伤害冷却。血量归零会失败，撑过最后一波则胜利。·
- 游戏中会随机刷新药水，喝下可以回复血量。


## 仓库结构

- `spec/`：当前版本目标、产品范围和交付规格。
- `assets/`：游戏资源文件。
- `docs/`: 记录和项目有关的文档。
- `scenes/`：Godot 场景文件。
- `scripts/`：GDScript 游戏逻辑、调试入口和测试脚本。
  
## 操作方式

- 移动：WASD / 方向键
- 选择升级：鼠标点击
- 暂停：Esc / P

## 技术栈

本游戏使用 Godot 4.x 和 GDScript 开发，目标是做成一个轻量、完整、能直接游玩的一局制 2D 小游戏。
